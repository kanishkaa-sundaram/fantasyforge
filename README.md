# 🧙 FantasyForge – Interactive Fantasy Character Creator

FantasyForge is an interactive fantasy character creator that lets users create unique RPG characters with custom names, classes, portraits, backstories, and character statistics. Build your own fantasy heroes and save them to a personal character deck!

## ✨ Features

- **Character Generation:** Generate fantasy characters with unique names and character classes.
- **Character Portraits:** Create fantasy-themed character portraits based on the selected character class.
- **Custom Backstories:** Generate creative backstories for your characters.
- **RPG Statistics:** View character attributes such as Health, Mana, and Strength.
- **Save to Deck:** Save created characters and revisit your collection.
- **Fantasy-Themed Interface:** Explore a visually engaging interface inspired by fantasy RPG worlds.

## 🎮 How It Works

1. Open FantasyForge.
2. Generate a new fantasy character.
3. Explore the character's name, class, and portrait.
4. Generate and read the character's backstory.
5. View the character's RPG statistics.
6. Save your favourite characters to your deck.
